# 经济系统审计报告代码级核实 (`ECONOMY_AUDIT_VERIFICATION.md`)

> **核实基准与约束声明**：
> 1. 本文档严格以当前仓库实际源码（Web `src/` 与 iOS `ios-native/HungrySharkEvolution/`）为唯一真相源，对 [`ECONOMY_SOURCE_SINK.md`](./ECONOMY_SOURCE_SINK.md) 中的每一条结论、公式、汇总数值及跨平台行为进行逐项代码级核实。
> 2. **严格区分三类数据性质**：
>    - **[代码实际值]**：直接从源码字面常量与条件表达式读出的数值/公式。
>    - **[数学推算值]**：基于代码确定性公式严格求和、求积或极值推导出的精确结果（通过 `npx tsx` 演算校验，非玩家样本实测）。
>    - **[模拟估算值]**：依赖玩家行为假设（如每分钟捕鱼数、拾取率、单局时长、王冠达成率等）的推演值；**不可视为真实线上平均值**。
> 3. **核实结果状态定义**（仅使用以下四态）：
>    - `VERIFIED`：代码确认完全一致
>    - `INCORRECT`：报告结论、数值或机理与代码实装存在明确矛盾
>    - `PARTIAL`：主干结论或部分数值成立，但存在未披露前提、公式缺漏、统计边界偏差或另一端行为遗漏
>    - `UNVERIFIED`：基于当前仓库源码/无线上埋点数据，无法确认真实运行时均值或生产环境外置参数

### 2.3 报告遗漏的跨平台核心分歧清单（10 项）

1. **狂暴（Frenzy）收益倍率**：Web 在狂暴期间吞噬直接金币与基因 `×2`（`rules.ts:736`）；iOS 狂暴对币种收益无任何倍率（`PreySimulation.swift:386`）。
2. **狂暴触发阈值与冷却**：Web 需 `8` 条黄金鱼（开局 `12s` 保护、`25s` 冷却）；iOS 仅需 `5` 条黄金鱼、`0s` 冷却。
3. **变异种生态**：Web `GOLDEN` `2.5%~5.5%` + `ABYSS_BEHEMOTH` `8%~30.5%`；iOS 固定 `8.0% GOLDEN_SWARM` 且 **`0% ABYSS_BEHEMOTH`**。
4. **单鲨战力技能效果**：`GoldOverdrive` 在 Web 为 `4.5s+ / +45 HP / 可连续使用`，iOS 为 `8.0s+ / 回满血 / 狂暴期禁用`；`GeneSurge` 在 Web 为 `+30 HP`（可触发完成新手第 3 步），iOS 为 `+35 HP`。
5. **试玩对象与规格**：Web 试玩固定 `#41 歼星舰 Lv.10 + 4.5s 狂暴`；iOS 试玩 **下一只未解锁鲨鱼 `max(5, saved)` 级 + 0s 狂暴**。
6. **XP 与积分连击加速差异**：Web 普通 XP 乘 `0.55`、狂暴乘 `0.22`；iOS 全额 `1.0x` XP、黄金 `3x`、破甲 `1.5x`。iOS `HuntingHeatBuff` 加 `1.15x~1.6x` 得分，Web `HuntingHeatBuff` 加磁吸半径与回能，从而令相同游戏时长下双端的 `reqMaxInRunLevel` 与王冠解锁速率大幅偏离。
7. **`DOUBLE_SETTLEMENT` 口径**：iOS 仅存在于局末结算，且按 **毛收益累计** `runCoinsEarned / runGenesEarned`（不扣减局内强化/狂暴花销，含悬赏奖励，不含王冠奖金）；Web `runSnapshot.coinsEarned` 为 `endCoins - startCoins` 净变化且仅作展示。
8. **解锁父级链路**：Web `getParentCandidatesForForm` 支持“左侧前驱 OR 上代同列祖先”；iOS 仅认线性前驱 `index - 1`。
9. **王冠发奖时机**：Web 局内 `120ms` 节拍实时入账（可当场花掉升级）；iOS 仅局末结算入账。
10. **掉落物物理生命周期与磁吸**：Web 掉落物永不消失；iOS 拾取物 **`11.0s`** 自动销毁（`OceanGameScene.swift:139`），且 iOS 狂暴有专用 `390px` 磁吸增强（Web 靠 `stats.magnetRadius * 1.35`）。
