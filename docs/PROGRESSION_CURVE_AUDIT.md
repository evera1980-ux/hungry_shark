## 2. 三类成长曲线核心异常深度诊断

### 2.1 断崖式成本增长（Cost Cliffs）

1. **跨代强制强化“双倍跳跃崖”（`#15→#16`, `#31→#32`, `#39→#40`）**：
   - `#14 → #15` 父强化费为 `539C / 0G`，而 `#15 → #16` 要求 `reqParentUpgradeLevel` 从 `4` 升至 `5`，立刻触发 `Lv.4→5` 基因突破门槛，**父强化费用跳升至 `928C + 85G`**。
   - `#30 → #31` 父强化费为 `7,812C + 489G`，而 `#31 → #32`（进 G5）要求父级从 `Lv.6` 跳升到 `Lv.8`（叠加 baseCost 跃升），**父强化成本暴涨 `2.23×` 至 `17,428C`（加上 `#32` 自身解锁 `9,500C` 合计 `26,928C`，创单阶跨度最大涨幅）**。
2. **本末倒置的“父级强化费 > 新鲨鱼解锁费”（G5 & G6 普遍现象）**：
   - 因为 `baseUpgradeCoinCost` 仅从解锁费的 ~`1/10` 起步，但 `1.36^(lv-1)` 升至 `Lv.8` 需消耗 `16.8 × base`，升至 `Lv.9` 需 `23.9 × base`：
   - 解锁终极鲨 `#47` 仅需 `44,400` 金币，但必须先把 `#46` 升到 `Lv.9`，**花掉 `113,574` 金币（解锁费的 `2.56` 倍！）**。玩家感觉不是在“攒钱买新鲨”，而是在给即将淘汰的旧鲨交天价过路费。
3. **局内等级门禁 `Lv.16 → Lv.18` 的单局时长悬崖**：
   - 达成 `reqMaxInRunLevel = 12` 需单局累计 **`24,688` XP**（G4 约 `16.0` 分钟纯狩猎），`Lv.18` 需 **`74,743` XP**（G6 约 `14.2` 分钟纯狩猎）。而此时 `globalDifficultyMultiplier` 每 `60s` 叠加 `+10%` 饥饿扣血，普通玩家极难在单局中坚持到 `14` 分钟，往往被迫反复看复活广告或靠 `GeneSurge` 硬冲。

### 2.2 无意义升级与体验倒挂（Regressive & Desynced Upgrades）

1. **`rules.ts` 与 `sharkEvolutionConfig.ts` 的“基因突破空心化”错位（高危设计缺陷）**：
   - [`sharkEvolutionConfig.ts:969-985`](../src/game/sharkEvolutionConfig.ts#L969-L985) 与 [`GameRules.swift:241-251`](../ios-native/HungrySharkEvolution/Core/GameRules.swift#L241-L251) 明确把基因突破收费节点定在 **`Lv.4→5`** 与 **`Lv.9→10`**，代码注释也写明用于“+1 咬合阶位突破”。
   - **但 [`src/game/rules.ts:447-449`](../src/game/rules.ts#L447-L449) 实际发奖节点却写成了 `upLv >= 3 (+1T), >= 6 (+2T), >= 10 (+3T)`！**
   - 直接导致三大恶果：① 玩家花 `13 ~ 2,995` 基因冲破 `Lv.4→5` 时 **`biteTier` 纹丝不动（`+0`）**；② G1 仅需 `Lv.3`（`0` 基因）就提前白嫖了 `+1T`；③ G6 要求 `reqParentUpgradeLevel = 9`，刚好停在 `Lv.9→10` 终极突破前一格。
2. **全链条 95% 进化瞬间战力缩水（Evolution Power Dip）**：
   - 实测全 47 次从“上阶强制等级 `Lv.req`”进化到“本阶 `Lv.1`”的数据：
     - 仅有 **1 / 47**（`#0→#1`）实现了三围全面正向成长（`T+1 / HP+28% / 速+5%`）；
     - **45 / 47** 次进化瞬间 **HP 暴跌 `-4%` 至 `-45.6%`**（最恶劣点：`#42 Lv.9 物理进化` `2,308 HP` → `#43 Lv.1 元素` `1,256 HP`，直接腰斩）；
     - **37 / 47** 次进化瞬间 **移速倒退 `-1%` 至 `-11.3%`**；
     - **23 / 47** 次进化（**`#23 → #46` 连续 23 阶无一例外**）甚至出现 **咬合阶位 `-1T` 倒退**（因 `reqParent >= 6` 触发 `upgradeBiteBonus = +2`，使旧鲨 `baseT + 2` 高于新鲨 `Lv.1` 的 `baseT + 1`）。
     - 玩家刚砸下数万金币+数千基因买下新鲨鱼，开局瞬间发现**咬合变低、血条变脆、游速变慢**，正反馈严重受损。

### 2.3 成长空档与内容断层（Progression Gaps）

1. **`T33 ~ T36` 连续四阶“零猎物荒漠”**：
   - 全库 234 种猎物中有 `16` 个咬合阶位处于空白（`T4~6, T9, T12, T17, T19, T21, T25~27, T30, T33~36`）。其中 **`#32 ~ #35`（`21.5m ~ 26m`）刚好对应 `T33 ~ T36` 全空档**，且 `#34` 与 `#35` 在 Z1 浅海可食种数为 `0`，全图仅剩 `13` 种可吞猎物，形成游戏中期最明显的“没合适的鱼吃”空档期。
2. **终局深度 `1,450m` 与海洋 `11,000m` 脱节**：
   - 玩家只需到达 `1,450m`（第 3 层半深海顶部）即可满足全游戏所有 48 只鲨鱼的深度门禁；而 `PREY-301..400` 分布在 `4,000m ~ 11,000m`，缺少阶段性深海门禁与高阶深潜回报驱动。
3. **试玩广告破坏门禁闭环**：
   - `TRIAL_MAX_MECHA` / `TRIAL_SHARK` 未隔离 `bestInRunLevel` 与 `bestDepthReached` 写入，新手首局看一次试玩广告即可永久击穿后续 47 阶的全部等级与深度前置门禁。

### 3.2 三类玩家模型的核心启示

1. **Web 端不能直接照搬目前数值上 P2-1 奖励**：普通玩家 `6.7` 天、高活跃玩家 `2.1` 天就毕业 48 阶，且基因毫无消耗瓶颈；若 P2-1 的每日任务、Boss 首杀和 7 日登录继续发大量金币与基因，Web 毕业时间将被压缩至 **`1~3` 天内**。
2. **iOS 端必须在“压低前期过剩、补充中期基因、缩放后期广告”之间重平衡**：目前 iOS 轻度玩家受 `38%` 基因概率门控长达 `71.7` 天才会见底，且 `G3~G4` 连续 `28` 天卡在同代极易流失；而高活跃玩家靠固定 `300C` 广告与前 3 代高额金币王冠 `2.8` 天就能穿完，出现严重的 **“贫富分化 + 前松后崩”**。
3. **仅解锁 `≠` 玩透**：若按“全 48 只升至 Lv.10”（`2,324,479C / 173,888G`）计算，总需求约为速通路径的 `1.63x` 金币与 `1.53x` 基因，但当前缺少让玩家去养旧鲨鱼的玩法理由（高阶单挑 Boss / 血统共鸣 / 周赛限制代际等）。
