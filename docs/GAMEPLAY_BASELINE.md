## 0. 六大核心审计维度结论总览

## 1. 现有核心玩法闭环拆解（Core Loops）

### 1.1 单局微循环（In-Run Micro Loop，60Hz 仿真）

1. **生存对抗饥饿（Metabolic Starvation Clock）**
   - 玩家在 2D 连续海洋中控制鲨鱼巡航与加速（Boost 消耗能量，水面 `y < 48 * worldScale` 额外 `+18/s` 换气回能，击杀猎物回复 `6 + round(tier * 0.45) + killEnergyBonus` 能量）。
   - 非狂暴状态下持续扣血：`metabolicBaseDrain = 2.6 + min(4.5, (level - 1) * 0.35)` 再乘 `globalDifficultyMultiplier` 与 `row * 0.04` 折扣，并随时间每 `60s` 提升 `+10%` 全球难度倍率（`infiniteProgressionManager.ts:52`），形成“必须不断猎食才能存活”的底层张力。
2. **吞噬矩阵与三态判定（`resolvePreyEncounter`）**
   - **`tierDiff <= 0`（直接吞噬 `DEVOUR`）**：回复 HP、获取 XP/Score/Coins/Genes，触发 `comboCount`（Web 3.2s 窗口 / iOS 4.2s 窗口，每次 `+8%` 倍率直至 `maxComboBonus`）与 `huntingHeatBuff` 热度阶梯（`heatLevel 0..5` 提供额外 `+15%..+120%` 磁吸半径与得分加成）。
   - **`1 <= tierDiff <= 3`（冲刺破甲 `ARMOR_CRUSH` / 失误受伤 `NEED_BOOST`）**：未冲刺会被撞伤弹开；按住冲刺可破甲击杀并获得额外 XP/奖励（iOS 显式给予 `armorHp` 多段撞击与 `2x` 分数）。
   - **`tierDiff >= 4`（致命天敌 `DEADLY_PREDATOR`）或水雷 `cyber_mine`**：只能靠 **Golden Frenzy（`biteTier = 48` + 无敌免疫）** 或特殊词条（如部分机械/泰坦鲨破雷）强吞。
3. **局内双触发事件与 MOBA 技能扇面**
   - **自然狂暴**：非狂暴期间吞噬 `8` 条黄金变异鱼（`GOLDEN_MUTANT`，基础刷率 `2.5%`，最高随分数升至 `~5.5%`；虚空/混沌血统可减免至 `3~7` 条）触发，冷却 `25s`。
   - **随机悬赏目标（Bounty Target）**：Web 需连续吞噬 **2 条**当前指定猎物（刷新权重占 `26%`），iOS 需 **3 条**。
   - **右下角 4 键快捷消耗**：
     - **黄金狂暴 (`GoldOverdrive`)**：消耗局外备份金币，立即开启 `4.5s + frenzyDurationBonus` 狂暴、回血 `+45`（iOS `+45%`? 需对照实际值：Web 固定 `+45 HP`）并回满能量。
     - **基因涌流 (`GeneSurge`)**：消耗局外备份基因，立即灌注当前升级条 `55%` 的 XP、回血 `+30` 并回满能量。
     - **躯体强化 (`UpgradeBody`)**：局内直接消耗备份金币/基因升级当前鲨鱼 `Lv.1 → Lv.10`，并触发 `morphFlash` 与 `+25%` 生命恢复。
     - **破茧进化 (`Evolve`)**：满足 5 重门禁后直接在海中完成跨阶进化，立刻回复全满 HP/能量并附带 `3.2s` 狂暴。

### 1.2 中长线养成循环（Meta Progression Loop）

1. **48 阶单一线性链条（6 代 × 8 列）**
   - 玩家从 `#0 shark_00_clown_fry`（`0.8m / T1`）起步，按索引 `0 → 47` 单线递进解锁至 `#47 shark_47_omega_devourer`（`45.0m / T48`）。虽有 **4 大血统** 标签交替穿插在 48 阶中（物理进化 / 赛博机械 / 元素超能 / 深渊古神），但 **没有分支树结构——所有玩家必须按同一顺序买完前一只才能买下一只**（`getParentCandidatesForForm` 仅返回 `[forms[index - 1]]`）。
2. **五重联合解锁门禁（`evaluateSharkUnlock`）**
   - 必须同时满足：① 父级鲨鱼已解锁；② 父级强化等级 `>= reqParentUpgradeLevel`（G1: `2~4`, G2: `4`, G3: `5`, G4: `6`, G5: `8`, G6: `9`）；③ 历史最高单局等级 `bestInRunLevel >= reqMaxInRunLevel`（`1 → 18`）；④ 历史最大下潜深度 `bestDepthReached >= reqMaxDepth`（`0m → 1,450m`）；⑤ 金币与基因余额充足。
3. **图鉴收集被动与单鲨王冠成就**
   - **图鉴全局被动 (`getGlobalAtlasBonuses`)**：每多解锁 1 条鲨鱼，全鲨获得 `+2% HP`、`+0.8% 移速`、`+2.5% 结算奖励倍率`（48 只全满时提供 `HP x1.94`、`移速 +37.6%`、`奖励 x2.175`）。
   - **单鲨三分段分数王冠 (`getSharkMasteryConfig`)**：每只鲨鱼设有铜/银/金 3 个一次性分数档位，达标即永久发放基因（iOS 额外发放金币）。

## 2. 新手引导、视口生态与双端体验基线

### 2.1 新手引导流程与保护期

- Web（`stepSimulation.ts`）与 iOS（`OceanGameScene.swift`）均实装 4 步非阻断引导：`EAT_SMALL_FISH (0/3)` → `HOLD_BOOST (0.7s Web / 1.2s iOS)` → `HANDS_ON_UPGRADE` → `CELEBRATE` → `DONE`。
- 引导期开启 `tutorialProtectionActive = true`，浅海强制只刷 `tier <= 2` 小鱼，降低首局挫败率。
- **首局资金投放双端差异**：
  - Web 初始存档 `120C / 25G`，完成第 2 步长按冲刺再发 `+80C / +20G` 新手礼包（合计 `200C / 45G`），足以无压力购买 `#0` 升级至 `Lv.3+` 并立刻解锁 `#1`（`95C / 20G`）。
  - iOS 初始存档 `120C / 15G`（少了 `10G`），完成第 2 步时若 `bankedCoins < firstCost` 则补齐差额至能升 1 级，**但因为 `#1` 解锁需要 `20G` 而初始仅有 `15G`**，iOS 新手首局若未随机触发 38% 基因拾取，反而会出现金币够却差 `5G` 无法在第一局无缝进化的卡顿感。

### 2.2 五层真实水深带与生物利用率（235 项配置实测）

通过分段像素-米深映射（[`depthScale.ts`](../src/game/depthScale.ts)）实测全库 234 种活跃海洋生物 + 1 种水雷 `cyber_mine` 的真实分布：

| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Z1 阳光浅海珊瑚区** | `0 ~ 2,000 px` | `0 ~ 200 m` | `117` 种重叠（`67` 种原生） | `T1 ~ T1`（原生中点均 `T1`） | `1.0 / 1.0` | **过载拥挤**：全库 89 种 `T1` 鱼类集中在此；体长 `>= 24.5m` 的鲨鱼（`#34~#47`）在 Z1 **可食种数为 `0`**，但每局出生仍在 `~22m` 浅滩。 |
| **Z2 暮光斜坡带** | `2,000 ~ 6,000 px` | `200 ~ 1,000 m` | `60` 种重叠（`25` 种原生） | `T1 ~ T15`（均值 `T6.0`） | `5.2 / 2.0` | **过渡断层明显**：`T4~T6, T9, T12` 共 5 个阶位彻底空缺。 |

| **Z5 冥渊超深海沟** | `16,000 ~ 20,000 px` | `6,000 ~ 11,000 m` | `127` 种重叠（`84` 种原生） | `T39 ~ T48`（均值 `T43.6`） | `82.9 / 25.0` | **终局富矿但无系统强牵引**：84 种高产粉红巨兽聚集于此，但没有任何解锁门禁、日常任务或 Boss 强制要求下潜至 `6,000m+`。 |

**关键利用率漏洞实锤**：
1. **16 个咬合阶位处于“零物种真空”**：`T4, T5, T6, T9, T12, T17, T19, T21, T25, T26, T27, T30, T33, T34, T35, T36` 在现役 234 种猎物中 `COUNT = 0`。其中 **`T33~T36` 连续 4 阶真空**，导致 G5 前半程（`#32~#35`）完全吃不到同阶猎物，只能越级俯冲吃 `T28~T32` 或强行冲刺破甲 `T37`。
2. **中后期巨鲨出生即遭“浅海饥荒”**：`stepSimulation.ts:469` 与 `OceanGameScene.swift:317` 均将所有鲨鱼固定出生在 `spawnY = max(220, round(22 * worldScale + 95))`（仅 `~22m~39m` 浅滩）。但 `ecosystemSpawner` 受真实物理体长过滤（`bodyLengthCm >= sharkLengthM * 13.3`），导致 `#34 (24.5m)` 至 `#47 (45m)` 在 Z1 可食种数为 **0**。尽管 1.5s 后会弹出“深潜提示”引导至 `663m~734m`，玩家每开一局都要先忍受 15~25 秒空海垂直下潜，打断爽感。
3. **试玩机制击穿全局成长门禁**：无论是 Web（`TRIAL_MAX_MECHA`，试用 `#41`）还是 iOS（`TRIAL_SHARK`），**试用局均在结束后把试玩鲨鱼跑出的 `level >= 5..12+` 与 `maxDepthReached >= 4,000m+` 写入正式存档的 `bestInRunLevel` 和 `bestDepthReached`**（仅 `settleSharkScoreMastery` 判断了 `trialActive` 跳过王冠奖励）。新手只要首局看 1 次试用广告，即可永久跳过后续全部 47 阶的深度与局内等级双门禁。

## 3. 玩家目标感与留存瓶颈诊断（Retention Diagnosis）

1. **短线驱动力充足，但中长线高度单一**：
   - 一旦进入 G2~G3，玩家唯一可感知的长期目标只剩下 **“攒金币/基因 → 买下一阶列表中的鲨鱼”**。由于 48 阶列表从 `#0` 到 `#47` 纯线性单轨推进，且 **#23 → #46 连续 23 次刚进化完的 Lv.1 新鲨鱼反而比刚养好的上一只 Lv.6~9 旧鲨鱼更弱**，玩家在付出高昂代价跨阶瞬间会体验到强烈挫败（“花了几万金币进化，结果新鲨鱼连刚才能咬死的鱼都咬不动了”）。
2. **血统同质化，缺乏构筑深度**：
   - `APEX_BIO / CYBER_MECHA / ELEMENTAL_CORE / ELDER_ABYSS` 目前主要表现为基础系数微调（血量/移速/饥饿减免/基因收益），以及少数鲨鱼隐藏在代码里的被动倍率（且 **iOS 端尚未同步除 Elder `1.15x` 外的多数特殊倍率**），局内缺乏“主动大招、元素连锁、机械激光或深渊黑洞”等可玩性差异。
3. **跨局目标真空，直接削弱 P2-1 上线基础**：
   - 当前版本没有 **每日/每周悬赏任务**、没有 **图鉴/生态里程碑成就**、没有 **阶段性深海领主 Boss 首杀挑战**。因此当玩家解锁到中后期（G4~G6），或通过一次高产局刷够基因后，便失去每天打开游戏的核心理由——这也正是引入 `P2-1`（血统主动技 + Boss 挑战 + 任务成就体系 + 混合变现）的根本业务原因。
