# 鲨鱼捕食游戏｜统一猎物数据库（Markdown）

> 数据量：100 种普通鱼类 + 30 种大型海洋生物 + 10 种巨型海洋生物，共 140 条。
> 用途：游戏猎物配置、美术资产生成、生态分层与进化关卡规划。
> 说明：水深、体长为近似生态参考值，不是每个物种的绝对边界；不同地区、年龄与季节可能变化。蝠鲼/鳐类采用翼展或体盘宽度作为尺寸基准；海洋哺乳动物的体长和游戏分档注明为设计参考。游戏精灵像素是推荐的初始显示范围，可按摄像机缩放与鲨鱼比例调整。
> 排除：蛇形鱼类、鳗鱼、海蛇、章鱼及鱿鱼。

## 字段说明

| 字段 | 含义 |
|---|---|
| ID | 唯一资产 ID；普通 PREY-001–100，大型 PREY-101–130，巨型 PREY-201–210 |
| 水深_m | 常见活动水深范围，单位米 |
| 体长_cm | 参考长度范围，单位厘米；另有尺寸基准字段说明体长/翼展/体盘宽度 |
| 游戏尺寸级别 | XS / S / M / L / XL / XXL / 巨型 |
| 建议精灵尺寸_px | 初始渲染尺寸范围，非真实尺寸换算 |
| 生成海域 | 根据水深最小值粗分生态区，游戏可覆盖 |
| AI生图提示词 | 已拼接统一风格前缀与负面提示词，可单条复制 |
| 备注 | 数据需逐物种核验；本表为游戏素材规划版本 |
